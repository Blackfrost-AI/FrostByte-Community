# u1tra_instinct

Collaborator theme for keys 🧪 (@u1tra_instinct), based on the approved September 17 concept. Uses the original profile avatar only; no X banner.

Select **Settings → Interface → Appearance → u1tra_instinct**. Palette: acid lime `#C4FF00`, near-black `#080D06`, dark olive `#131B0D`, warm white `#F4F1E6`. Tiny original SVG pixel vials accompany the avatar.

Departure Mono 1.500 is bundled locally and used throughout: title, navigation, controls, settings, conversation, composer, editor, diffs and terminal. The title and body use the same font. The theme intentionally overrides Studio's normal prose-font preference. Other themes retain their existing typography. Font binaries are unchanged; full SIL OFL notices and checksums are bundled.

Avatar provenance: https://x.com/u1tra_instinct (public avatar metadata retrieved via https://api.fxtwitter.com/u1tra_instinct), image https://pbs.twimg.com/profile_images/1935918094548955136/QHZz0yE6.jpg. Avatar remains collaborator artwork, not relicensed as application code. Private local build and review only.
