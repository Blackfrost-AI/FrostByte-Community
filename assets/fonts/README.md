# Blackfrost and AEON Orbit fonts

Blackfrost uses Manrope for reading, controls, and weighted display headings,
with the platform's native monospace for transfer data. It does not reuse
AEON's Orbitron headings. Manrope is bundled unchanged;
its [complete notice](../../licenses/fonts/manrope/OFL.txt) and pinned upstream
source/checksum are retained alongside the other fonts. No font service is used.

Orbitron and Share Tech Mono are bundled unchanged under SIL OFL 1.1.
The complete upstream copyright and license text is retained in
[Orbitron notices](../../licenses/fonts/orbitron/OFL.txt) and
[Share Tech Mono notices](../../licenses/fonts/sharetechmono/OFL.txt).
These notices ship in the desktop application's Legal resources.

[sources.json](sources.json) records the contributed font hashes and pinned
upstream license sources. Both notices match the copyright statements
embedded in the respective font files.

The proposed Valorax face is not included. See the
[AEON theme design system](../../docs/AEON-THEME.md).

Founders Leather (`jensen`) uses Space Grotesk 2.0.0 by Florian Karsten for
wide-tracked geometric display and interface typography, bundled unchanged under
SIL OFL 1.1 with its [complete notice](../../licenses/fonts/space-grotesk/OFL.txt).
